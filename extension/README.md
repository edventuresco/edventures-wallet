# My Little Wallet 🦄

An LLM-first browser extension wallet that uses generative UI components to provide an intelligent, conversational crypto wallet experience.

## 🎯 Project Vision

Traditional crypto wallets overwhelm users with complex interfaces. My Little Wallet changes this by letting you talk to your wallet naturally. Ask questions in plain English, and the AI generates beautiful, contextual interfaces on the fly.

**Example**: "Show me my Bitcoin balance" → AI instantly generates a sleek balance card with insights and suggested actions.

## 🏆 Hackathon Project

This project was developed using **prompt-led development** methodology to demonstrate transparent, auditable AI-assisted development.

### Judge Walkthrough

1. **Read the prompts**: Open [PROMPTS.md](./PROMPTS.md) and read prompts in chronological order
2. **Check git history**: For each prompt, examine the git commits:
   - `prompt: <title>` commit shows the prompt being recorded
   - `progress: <title>` commit shows the implementation
3. **Review planning**: Check [planning/](./planning/) for requirements, architecture, and decisions
4. **Run the demo**: Follow installation instructions below

This creates a complete audit trail showing exactly how the AI agent was used to build this project.

## ✨ Features

- **Natural Language Interface**: Talk to your wallet like you would to a person
- **Generative UI**: Dynamic, context-aware interfaces generated by AI
- **LLM-Powered**: Uses Claude API for intelligent understanding and response
- **Blockchain Integration**: Real-time balance and transaction data
- **Browser Extension**: Works directly in Chrome/Firefox
- **Secure**: Following Manifest V3 security best practices

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ or Bun
- Chrome or Firefox browser
- Claude API key (get one at [console.anthropic.com](https://console.anthropic.com))

### Installation

1. Clone the repository:
```bash
git clone https://github.com/BitHighlander/my-little-wallet.git
cd my-little-wallet
```

2. Install dependencies:
```bash
npm install
# or
bun install
```

3. Create `.env` file:
```bash
cp .env.example .env
# Edit .env and add your API keys
```

4. Build the extension:
```bash
npm run build
# or
bun run build
```

5. Load in browser:
   - **Chrome**: Navigate to `chrome://extensions/`, enable "Developer mode", click "Load unpacked", select the `dist` folder
   - **Firefox**: Navigate to `about:debugging#/runtime/this-firefox`, click "Load Temporary Add-on", select the `manifest.json` in `dist` folder

## 🔑 Environment Variables

Required environment variables (see `.env.example`):

```bash
# Claude API Key (required)
VITE_ANTHROPIC_API_KEY=your_claude_api_key_here

# Blockchain RPC URL (required for Ethereum)
VITE_ETHEREUM_RPC_URL=https://mainnet.infura.io/v3/your_infura_key

# Optional: Bitcoin RPC URL
VITE_BITCOIN_RPC_URL=https://blockstream.info/api
```

## 🎓 Development Methodology

This project follows a **prompt-led development** approach:

1. **Interview**: Capture requirements through structured questions
2. **Prompt Logging**: Every agent interaction logged in PROMPTS.md (append-only)
3. **Planning**: Maintain living documents in planning/ directory
4. **Commit Protocol**: Two commits per feature:
   - `prompt: <title>` - Records the prompt
   - `progress: <title>` - Records the implementation
5. **Validation**: Every deliverable includes tests or reproducible demos

See [CLAUDE.md](./CLAUDE.md) for the complete agent operating system.

## 🔒 Security Notes

**⚠️ Hackathon POC Only**: This is a proof-of-concept for demonstration purposes. Not production-ready.

- API keys stored in browser's local storage (encrypted by browser)
- Read-only wallet operations (no transaction signing in MVP)
- No private key handling
- Follow browser extension security best practices
