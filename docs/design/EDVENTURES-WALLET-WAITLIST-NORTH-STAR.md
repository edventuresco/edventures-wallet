# Edventures Wallet waitlist — North Star

## Purpose

Help the right parent understand Edventures Wallet quickly, trust it, and confidently reserve early access for $1.

## The core rule

> **Do not over-explain.**

Edventures Wallet should feel calm, capable, warm, and useful. It should never feel like a crypto pitch, a crowded fintech dashboard, or a children’s game asking for attention.

## The homepage has five jobs

1. Explain: a wallet for families.
2. Show: goals, funds, allowances, and learning.
3. Reassure: parents set the rules.
4. Differentiate: no trading clutter.
5. Convert: reserve early access for $1.

## One audience

Write to the parent making the decision—especially the parent who is interested in better financial tools but alienated by trading culture.

Children are users of the eventual product, not targets of the waitlist or payment flow.

## One CTA

Use only:

> **Reserve early access — $1**

Short header version:

> **Reserve for $1**

Every primary button begins the same reservation flow. Secondary links may navigate to page sections but may not visually compete.

## Messaging hierarchy

1. **Grow money confidence together.**
2. Save together, automate kids’ funds, and learn safely.
3. Parents remain in control.
4. One-time $1 founding-family reservation.

Do not lead with crypto, Bitcoin, market size, custody, chains, wallets, or competitor criticism.

## Copy budget

| Element | Limit |
|---|---:|
| Hero eyebrow | 5 words |
| Hero headline | 8 words per line |
| Hero support | 22 words |
| Section heading | 8 words |
| Section body | 18 words |
| Benefits | Exactly 3 |
| Benefit title | 4 words |
| Benefit body | 10 words |
| Steps | Exactly 4 |
| Step description | 5 words |
| Offer bullets | Maximum 3 |

If copy exceeds a limit, shorten it. Do not solve it with smaller type.

## Page structure

1. Hero
2. Three benefits
3. Four small steps
4. Trust/origin
5. Founding-family offer
6. Minimal footer

No FAQ on the homepage unless user research proves one objection is blocking conversion.

## Visual rules

- 60% sand, 25% forest, 10% terracotta, 5% ink.
- Fraunces for headings; Inter for UI and body.
- One dominant visual per section.
- Generous whitespace is part of the brand.
- Rounded cards and subtle depth.
- Hand-painted editorial illustrations only.
- Code-native interface icons.
- Terracotta is reserved primarily for conversion and progress.
- No neon, glassmorphism, token tickers, trading charts, casino cues, or cartoon overload.

## Tone

- Warm, direct, and intelligent.
- Speak parent-to-parent.
- Use familiar verbs: save, grow, learn, choose, join.
- Explain security in plain language.
- Be hopeful without promising returns.
- Never patronize parents or children.

## Trust

Trust comes from:

- showing the actual product;
- making parent permissions explicit;
- limiting data collection;
- using secure hosted checkout;
- being honest about early-access timing and the $1 fee.

Do not manufacture testimonials, user counts, partner logos, or security certifications.

## Mobile rules

- Design mobile independently.
- Stack rather than squeeze.
- Show one dominant phone.
- Use a full-width CTA.
- Hide desktop navigation.
- Benefits become vertical rows.
- Steps become a 2×2 grid.
- Remove decoration before shrinking whitespace or type.
- No sticky CTA covering content.

## Data and children

- Collect parent email and country only.
- Collect no child data on the waitlist.
- Do not track sensitive form fields.
- Do not target advertising to minors.
- Put Privacy and Terms before payment.

## Anti-patterns

Reject any iteration containing:

- more than five main sections;
- paragraphs longer than three lines;
- several equally prominent CTAs;
- a wall of feature bullets;
- fake testimonials or vanity counters;
- unqualified market claims;
- speculative investment promises;
- named competitor attacks;
- “web3” in the hero;
- a desktop layout merely scaled down and labeled mobile;
- essential text baked into generated images.

## Pre-ship check

- [ ] Can a parent explain Edventures Wallet after five seconds?
- [ ] Is the CTA obvious without scrolling?
- [ ] Is the $1 clearly one-time?
- [ ] Are permissions visible?
- [ ] Is mobile genuinely mobile?
- [ ] Is every section doing one job?
- [ ] Can one sentence or element be removed?
- [ ] Are all claims true and supportable?
- [ ] Is no child data collected?
